# pd — 拼豆小程序

## 目录说明

| 目录 | 说明 |
|---|---|
| `AIxcx1/` | **主版本**（28 个页面，最新） |
| `yuandaima/` | 参考素材（非项目代码） |

## 项目概况

- 技术栈：微信小程序原生 + 微信云开发
- 主包体积：1.15 MB（上限 2 MB）
- TabBar：首页 / 发现 / 广场 / 我的
- 云函数：login、createUser、getMobile、ai-generator、template-api、security-api
- 核心页面：图纸生成、抠图、色卡、商城、仓库、订单、广场社区
